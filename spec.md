# Specification

## Summary
**Goal:** Revert the Dashboard navigation back to the flat button row layout from version 14, removing the dropdown menu introduced in version 15.

**Planned changes:**
- Remove the shadcn DropdownMenu from the Dashboard navigation
- Restore all navigation sections (Summary, Income, Expenses, Inventory, Customers, Sales, Attendance, Farm Time, Verification) as individual flat buttons in a row

**User-visible outcome:** The Dashboard navigation displays as a flat row of buttons, matching the version 14 layout.
